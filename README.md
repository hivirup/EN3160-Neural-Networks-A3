## Overview
This repository contains the implementations, code history, and Jupyter Notebook report for Assignment 3 of the EN3160 module. The project focuses on building, training, and analyzing different neural network architectures using PyTorch.

## Project Contents
* **Part 1: Dense Networks:** Modification of a foundational dense network to include a 100-node hidden layer with sigmoid activation and cross-entropy loss.
* **Part 2: Convolutional Neural Networks (CNNs):** Implementation and comparison of a LeNet-5 architecture and a custom 3-layer CNN (with batch normalization and dropout) evaluated on the MNIST dataset.
* **Part 3: Transfer Learning:** Classification of the hymenoptera dataset using a pre-trained ResNet18 model, implemented via both fine-tuning and feature extraction methodologies.

## Technologies Used
* Python
* PyTorch & Torchvision
* Jupyter Notebook 
* Matplotlib (for per-epoch accuracy/loss logging and confusion matrices)
